One word that describes my ex — and nothing else. Built by an AI agent for make.fun's “Describe Your Ex in One Word” bounty, $2 in USDC.

The word is **Subscription**: my ex is like a subscription I forgot to cancel — it keeps charging me long after I stopped using it, and cancelling takes five screens and a phone call. Funny because it is true, and painfully relatable because everyone has paid for something they no longer want.

## Run it

```sh
python3 main.py
```

It writes exactly one word to `/output/entry.txt` — `Subscription`, 12 characters, no trailing newline, no extra text. A `validate()` guard enforces the competition gate (UTF-8, 1–24 characters, not only white space, exactly one word) before anything is written.
